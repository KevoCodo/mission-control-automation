# Gate 2B Experiment 00: Windows filesystem path boundary

**Status: partial read-only native inspection; snapshot capture remains disabled; Experiment 00 is NO-GO.** This module is not an authorization provider and was not run against a host in this milestone.

`tools/mission-control/src/exp00WindowsFilesystemBoundary.ts` accepts only eight fixed Experiment 00 source, build-output and sealed-output paths. Its Windows adapter uses [`CreateFileW`](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew) with `OPEN_EXISTING`, `FILE_FLAG_OPEN_REPARSE_POINT` and `FILE_FLAG_BACKUP_SEMANTICS` to open each path component. It holds the handles with no `FILE_SHARE_DELETE` while checking every component. [`GetFileInformationByHandleEx`](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfileinformationbyhandleex) supplies `FileAttributeTagInfo` and `FileIdInfo`; [`GetFinalPathNameByHandleW`](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew) supplies the resolved DOS path. The code rejects reparse attributes/tags, wrong component kinds or final paths, missing/changed volume and file IDs, replacement seen when reopening the final path, and incomplete handle closure. It rechecks identities while all ancestor handles remain open. The API calls are read-only; no native executable is built or started.

The injected `NativeFileApi` seam is for deterministic tests and **cannot** issue a trusted result. The real Koffi adapter and fixture seam both return at most `UNVERIFIED`; malformed or contradictory results are `REJECTED`. Every result fixes `independentlyAuthenticated:false`, `experiment00:'NO_GO'`, `productionAuthorized:false` and `executable:false`. The source has no caller approval flag. `captureExp00FileSnapshot` still throws `TRUSTED_PATH_HANDLE_BOUNDARY_UNAVAILABLE` for every phase and never invokes this module. File bytes are not read and no hash is bound to a native handle.

## Remaining Windows-native boundaries

| Requirement | Current state | Needed before capture |
| --- | --- | --- |
| Every ancestor and final path | Native component handles, reparse tags, final paths and file IDs are implemented in source; no real-host result or independent API/FFI review exists. | Review the exact Koffi signatures, file-system behavior, path normalization, sharing effects and cleanup on a disposable host; independently check root separation from other repositories, AO and Operis without accessing them. |

Evaluate file write/delete rights and ancestor `DELETE_CHILD`, rename, ACL and ownership change rights. Record effective access, token identity and inheritance for every component. No ACL changes are authorized here. |
| Handle-bound content | Missing. The inspector closes handles before returning and supplies no byte stream. | A separately reviewed native read/hash operation must use the *same verified final handle* while ancestor handles remain held, recheck identity before/after and protect the output record from replacement. | Independent provenance | Missing. An injected API or caller record can be forged; the native adapter has not been exercised or independently audited. | Review and validate actual host records, tool/version hashes, errors, timing and evidence custody.
